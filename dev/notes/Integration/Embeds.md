# Embeds

Blocks embedded from another note, and from inside callouts, must read the
ability block of the source note ([[Embedded Sheet]]) (#40). Before the fix,
these showed every ability as 10.

Expected (level 5, proficiency +3, STR 18, WIS 16):

- Athletics +7, Perception +6, Stealth +2
- Spell save DC 14, spell attack +6
- Hit points 22 (10 + CON 12)

The ability block is in a different section, so it is not part of this embed.
